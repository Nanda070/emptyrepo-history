# Конкурентное программирование #2

## 1. Car (Машина)
Создайте класс `Car`, реализующий интерфейс `Runnable`. У класса есть 2 поля данных: `int traveled` (пройденный путь) и `int fuel` (топливо). Значение fuel задается через конструктор. В методе run машина должна двигаться по 100 км до тех пор, пока в ней остается не менее 5 литров бензина, выводя имя текущего потока и `"brumm-brumm"`, после чего уменьшать количество топлива на 5. После каждых 100 км поток должен спать 2 секунды. Если машина больше не может ехать, выведите имя потока и сообщение `"stopped after: " + traveled`. После этого метод run завершается.

Создайте 5 потоков, каждый из которых принимает объект своего автомобиля. Топливо автомобилей должно быть случайным числом от 20 до 40.


## 2. Checker (Проверяющий)
Создайте программу, в которой в методе main объявляется массив из 10 элементов. Заполните массив случайными числами из интервала `[0, 10)`. Создайте 10 потоков, задачи которых задаются анонимной лямбда-функцией: `i`-й поток должен проверять `i`-й элемент массива на равенство значению `i`. Если значения равны, выведите: `"Heuréka a[<i>]==<i>"`, иначе выведите: `"Sajnos a[<i>] ==<a[i]>"` (к сожалению, равенства нет).


## 3. Read/Write (Чтение/Запись)
Создайте класс с именем `Helper`. У класса есть 1 `public static boolean B = false` поле данных.

Создайте два класса (`Reader` и `Writer`), каждый из которых реализует интерфейс `Runnable`. `Writer` в своем методе `run` в цикле должен работать до тех пор, пока время его работы не достигнет 5 секунд (без засыпаний), при этом значение `Helper.B` равно `false`. Затем он должен перезаписать это значение на `true` и вывести `"changed"`.

`Reader` в своем методе `run` должен работать (в цикле без засыпаний) до тех пор, пока значение `Helper.B` не изменится на `true`. После этого он должен вывести `"about to stop"` и время, в течение которого он работал.

Создайте по одному объекту `Reader` и `Writer`, затем запустите 2 потока с их помощью.


## 4. Info (Информация)
Создайте статический метод, который выводит на экран имя текущего потока и текущий момент времени (`Instant.now()`), затем засыпает на случайное время из интервала `[1200, 1500)` миллисекунд, и снова выводит эту информацию на экран.

Создайте программу, которая добавляет в список 3 потока, передавая в их конструктор ссылку на вышеуказанную функцию в качестве метода-ссылки (method reference). С помощью цикла вызовите метод `run()` на каждом из 3 потоков, а затем с помощью другого цикла вызовите метод `start()` на каждом из 3 потоков. Что вы заметите?
