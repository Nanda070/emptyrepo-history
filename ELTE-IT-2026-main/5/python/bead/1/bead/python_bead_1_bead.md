# Python-React-IOT-dashboard
Панель управления IoT-устройствами с REST API на FastAPI и фронтендом на React.

Приложение не завершено.

## Настройка


### Сервер
Для настройки бэкенда выполните следующую команду в директории `server`:

```shell
pip install -r requirements.txt
```

После этого запустите `main.py` с помощью:

```shell
python -m uvicorn main:app
```

(Или `py`/`python3`, если команда `python` не работает.)

### Клиент
Для настройки фронтенда выполните следующую команду в директории `client` (требуется Node.js):

```shell
npm i
```

После этого для запуска сервера разработки клиента выполните:

```shell
npm run dev
```
