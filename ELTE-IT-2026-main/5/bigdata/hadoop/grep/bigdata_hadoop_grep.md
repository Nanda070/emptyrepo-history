# Grep

Напишите программу MapReduce, которая ищет заданную строку во входном файле. Выведите те строки из входного файла, которые содержат искомую строку.

Пример:
Искомая строка: "sütsz"

Содержимое входного файла:
Mit sütsz kis szűcs,
tán sós húst sütsz
kis szűcs?

Ожидаемое содержимое выходного файла:
Mit sütsz kis szűcs,
tán sós húst sütsz
