# Учебные материалы ELTE IK

В этом репозитории содержатся учебные материалы, подготовленные и собранные мной во время обучения на бакалавриате по специальности «Программная инженерия» (BSc). Это форк и перевод оригинального репозитория от Valentinusz - [elte-ik-bsc](https://github.com/Valentinusz/elte-ik-bsc)

Предметы сгруппированы по семестрам, в которых они изучались. Если вы не нашли какой-то предмет в конкретном семестре, стоит заглянуть в папки других семестров. Так-же имеется связь и план обучения в Obsidian

## [Конспекты](https://valentinusz.github.io/notes)

На данный момент доступны конспекты по следующим предметам:
- Продвинутая Java (неполный [мало примеров, нет темы NIO])
- Базы данных II
- Архитектуры Big Data и методы анализа
- Теория вероятностей и статистика (F)
