# rest-api

> REST API для домашнего задания по созданию пошаговых опросников

## О проекте

Этот проект использует [Feathers](http://feathersjs.com) — фреймворк с открытым исходным кодом для разработки API и приложений реального времени.

## Начало работы

1. Убедитесь, что у вас установлены [NodeJS](https://nodejs.org/) и [npm](https://www.npmjs.com/).
2. Установите зависимости:

    ```
    cd path/to/rest-api
    npm install
    ```

3. Запустите приложение:

    ```
    npm run migrate # Запуск миграций для настройки базы данных
    npm start
    ```

## Тестирование

Запустите `npm test`, чтобы запустить все тесты в папке `test/`.

## Генерация кода (Scaffolding)

В этом приложении используется мощный CLI для Feathers. Несколько примеров того, что он умеет:

```
$ npx feathers help                           # Показать все команды
$ npx feathers generate service               # Создать новый сервис (Service)
```
