## ℹ️ Общая информация
Здесь содержатся файлы практических и лабораторных занятий. Они предназначены для разбора тем, рассматриваемых на лекциях.

## 🛠️ Инструкции для чайников (Haskell)
Запускайте файлы `.hs` через интерпретатор GHCi:
1. Установите Haskell GHCup.
2. В терминале в этой папке введите `ghci <ИмяФайла>.hs`.
3. Для тестирования функций вводите их названия с аргументами (например, `isEven 4`).
