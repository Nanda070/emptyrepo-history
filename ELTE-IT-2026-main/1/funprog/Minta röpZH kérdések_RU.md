### Вопросы:

1. **Какое из следующих утверждений верно для языка Haskell?**
   * a) В Haskell обязательно указывать тип каждого выражения.
   * b) В Haskell нельзя определять собственные операторы, можно использовать только встроенные.
   * c) Haskell — это чисто функциональный язык со строгим (greedy/eager) вычислением.
   * d) Haskell — это чисто функциональный язык с ленивым (lazy) вычислением.

2. **Определение какой функции из следующих является тотальным (не частичным / non-partial)?**
   * a) `tail`
   * b) `init`
   * c) `last`
   * d) `take`

3. **Какое из следующих утверждений ложно?**
   * a) Если функция рекурсивна, она прямо или косвенно ссылается на себя.
   * b) Функция `foldr` определена рекурсивно.
   * c) Рекурсивная функция может иметь любое количество параметров.
   * d) Для каждой рекурсивной функции должен быть указан хотя бы один базовый случай.

4. **Что верно для лямбда-функций в Haskell?**
   * a) Они могут быть определены путем введения нового типа.
   * b) Их можно передавать в качестве параметров функциям высшего порядка.
   * c) Это другое название для операций композиции.
   * d) Тип лямбда-выражений невозможно вывести или указать.

5. **Что из следующего является классом типов (typeclass)?**
   * a) `Int`
   * b) `Bool`
   * c) `Integral`
   * d) `Double`

6. **Какое выражение грамматически корректно?**
   * a) `8 mod 5`
   * b) `3 mod 5`
   * c) `6 (mod) 6`
   * d) `(1) mod (7)`

7. **Каков результат выражения `1 < (1,2)`?**
   * a) Ошибка времени компиляции (разные типы).
   * b) `True`
   * c) `False`
   * d) Ошибка времени выполнения.

8. **Что называется частичным применением функции (partial application)?**
   * a) Когда частичная функция вызывается с параметром, для которого она не была определена.
   * b) Когда мы передаем функцию в качестве параметра другой функции.
   * c) Когда функция ссылается на саму себя для решения подзадачи.
   * d) Когда функции с `n` параметрами передается меньше, чем `n` параметров.

9. **Когда язык программирования называют чисто функциональным?**
   * a) Если в нем можно использовать функции высшего порядка.
   * b) Если в нем отсутствуют побочные эффекты (side effects).
   * c) Если в нем используется метод Каррирования (Currying).
   * d) Если он имеет ленивое вычисление.

10. **Каким может быть тип выражения `map (even . (+1))`?**
    * a) `Integral a => (a -> a) -> [a] -> [a]`
    * b) `Integral a => [a] -> [Bool]`
    * c) `Integral a => [a] -> [a]`
    * d) `[a] -> [Bool]`

11. **Какое из следующих выражений эквивалентно генератору списка `[f x | x <- ls]` для конечного списка `ls`, который вычисляется без ошибок?**
    * a) `foldr f [] ls`
    * b) `map f ls`
    * c) `filter f ls`
    * d) `any f ls`

12. **Каков тип выражения `(\x -> x:[x])`?**
    * a) `a -> [[a]]`
    * b) `a -> a`
    * c) `a -> [a]`
    * d) `[a] -> a`

13. **Каков результат выражения `length []:[]`?**
    * a) `0`
    * b) `[0]`
    * c) Ошибка времени компиляции
    * d) Ошибка времени выполнения

14. **В чем разница между шаблонами `_` (wildcard) и `x`?**
    * a) `x` можно использовать только как головной элемент списка, а `_` — в любом месте шаблона.
    * b) `_` используется, когда мы хотим обрабатывать значения типов, отличных от указанных в объявлении типа.
    * c) В одном шаблоне `_` может встречаться несколько раз, тогда как `x` — не более одного раза.
    * d) В одном шаблоне `_` может встречаться несколько раз, и представляет случайное значение в теле функции.

15. **Что означает шаблон `(xs:x:y)`?**
    * a) Соответствует любому списку.
    * b) Соответствует списку, содержащему как минимум два элемента.
    * c) Соответствует списку, состоящему ровно из трех элементов.
    * d) Список как минимум из двух элементов, последними двумя элементами которого будут `x` и `y`.

16. **Какому выражению соответствует шаблон `[]:x`?**
    * a) `[[1], [2]]`
    * b) `[[]]`
    * c) `[]`
    * d) `[[1,2]]`

17. **Каков результат следующего выражения?**
    `filter (== 2) ([1..] ++ [1,2])`
    * a) `[2,2]`
    * b) Выведет одну двойку, а затем зависнет (будет работать бесконечно).
    * c) Ошибка времени компиляции.
    * d) Не остановится и ничего не выведет.

18. **Какое утверждение о списках в Haskell верно?**
    * a) Списки гетерогенны (могут содержать элементы разных типов).
    * b) Списки гомогенны (могут содержать только элементы одного типа).
    * c) Списки обязательно имеют конечную длину.
    * d) Любой список можно построить только одним способом — с помощью оператора `(:)`.

19. **Что из следующего НЕ может быть типом выражения `Just "true"`?**
    * a) `Maybe [Char]`
    * b) `Maybe String`
    * c) `Maybe Bool`
    * d) Любой из вышеперечисленных вариантов.

20. **Рассмотрим следующее определение: `data D = A Int | B Int [Char]`. Каков тип выражения `B 42`?**
    * a) `D`
    * b) `String -> D`
    * c) `B Int`
    * d) `D -> String`

*   **11-20:** b, c, b, c, b, b, b, b, c, b
