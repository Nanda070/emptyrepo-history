## 📖 Описание задачи

В этом задании вам предстоит реализовать утилиту `reverse` (на основе стандартной Unix-утилиты `rev`). 

Программа должна выводить строки из указанных файлов (или со стандартного ввода, если файлы не заданы) на стандартный вывод (stdout) в **обратном порядке строк**, при этом **символы в каждой строке также должны быть перевернуты** (отзеркалены), и строки должны быть **пронумерованы**.

### Пример работы
Предположим, файл `test.txt` содержит:
```text
alma
barack
szilva
```

При запуске программы `./reverse test.txt` вывод должен быть следующим:
```text
3 avlizs
2 kcarab
1 amla
```

### Пример обработки нескольких файлов
Если один и тот же файл `test.txt` передан дважды в качестве аргументов: `./reverse test.txt test.txt`, вывод будет:
```text
3 avlizs
2 kcarab
1 amla
3 avlizs
2 kcarab
1 amla
```

## ⚙️ Требования к программе

1.  **Параметры командной строки:**
    *   Программа считывает содержимое файлов, переданных в качестве аргументов командной строки.
    *   Если при открытии какого-то файла возникает ошибка (файл не найден или нет прав доступа), выведите в поток стандартной ошибки (stderr) сообщение: `File opening unsuccessful!`, и перейдите к обработке следующего файла.
    *   Если аргументы не переданы, программа должна считывать строки со стандартного ввода (stdin). В этом случае программа не должна выводить никаких приглашений в консоль, а просто ожидать ввода.
    *   *Примечание:* Событие конца файла (EOF) вызывается сочетанием клавиш `Ctrl+D` на Unix-системах и `Ctrl+Z` на Windows.

2.  **Управление памятью и динамические массивы:**
    *   Мы предполагаем, что любой файл целиком помещается в оперативной памяти.
    *   Для хранения строк необходимо использовать **динамический массив** (выделение через `malloc`).
    *   При инициализации установите фиксированный размер массива (например, 8 элементов).
    *   Не пытайтесь заранее подсчитать количество строк в файле! Вместо этого **удваивайте размер массива** (`realloc`) каждый раз, когда количество считываемых строк превышает текущую емкость массива.
    *   Если выделение памяти завершилось неудачно на любом этапе, выведите сообщение об ошибке `Memory allocation failed!` в stderr и завершите выполнение с ненулевым кодом возврата.
    *   Максимальная длина одной строки гарантированно составляет не более **1024 символов**.

3.  **Модульная структура проекта:**
    *   Разделите программу на несколько единиц трансляции (модулей).
    *   Функция `main` должна находиться исключительно в файле `main.c`.
    *   Все остальные функции (например, переворота строки, чтения файлов, работы с массивом) должны быть реализованы в других файлах исходного кода `.c`, к которым должны прилагаться соответствующие заголовочные файлы `.h`.
    *   Защитите заголовочные файлы с помощью директив **header guard** (`#ifndef`, `#define`, `#endif`).

## 🚫 Ограничения и критерии оценки

*   **Код, который не компилируется, автоматически оценивается в 0 баллов.**
*   Использование **глобальных переменных** строго запрещено (ведет к снижению баллов).
*   Программа должна быть логически структурирована на отдельные функции.
*   **Утечки памяти запрещены!** Убедитесь, что вся выделенная динамическая память освобождается через `free()`. Проверяйте программу с помощью утилиты `valgrind` перед отправкой.
*   Избегайте неопределенного поведения (Undefined Behavior).
*   При считывании строк с помощью `fgets` не забывайте, что функция считывает и символ перевода строки `\n`. Его необходимо корректно обрабатывать или удалять перед переворотом строки.
