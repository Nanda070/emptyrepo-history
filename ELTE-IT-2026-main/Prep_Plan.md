## 🛠️ Фаза 1: Окружение и Инструментарий (Неделя 1)
*Прежде чем писать код, нужно настроить рабочее место профессионала.*

### 1.1. Терминал и Linux
В университете (и в реальной работе) мышь используется редко. Ваш лучший друг — командная строка.
> [!IMPORTANT] Ваша задача: установить WSL (Windows Subsystem for Linux), если вы на Windows, или использовать родной терминал на Mac/Linux.

**Базовые команды (выучить наизусть):**
* `pwd` (Print Working Directory) — где я нахожусь?
* `ls -la` (List) — показать все файлы, включая скрытые.
* `cd <путь>` (Change Directory) — перейти в папку. `cd ..` — на уровень выше.
* `mkdir <имя>` (Make Directory) — создать папку.
* `touch <файл>` / `rm <файл>` — создать / удалить файл.

📺 **Туториал:** [Курс молодого бойца по Linux (YouTube, 30 минут)](https://www.youtube.com/watch?v=wBp0Rb-ZJak)

### 1.2. Git и GitHub
Система контроля версий — это "сохранения" (как в играх) для вашего кода.
```bash
# Базовый workflow (рабочий процесс) каждый раз, когда вы написали код:
git add .                  # 1. Добавить все изменения в "корзину"
git commit -m "My update"  # 2. Упаковать изменения и дать им имя
git push                   # 3. Отправить в интернет (на GitHub)
```
📺 **Туториал:** [Git и GitHub для начинающих за 20 минут](https://www.youtube.com/watch?v=USjZcfj8yxE)

## 🧠 Фаза 2: Императивное программирование на C (Неделя 2-3)
*Предмет: Imperatív programozás. Самый жесткий предмет 1-го семестра.*

### 2.1. Базовый синтаксис
Язык Си не прощает ошибок. Здесь нет магии, вы сами управляете всем.

```c
#include <stdio.h>  // Библиотека ввода/вывода

int main() {
    int age = 20;
    // printf требует указания формата переменной: %d для int
    printf("Hello ELTE! I am %d years old.\n", age);
    return 0; // 0 означает успешное завершение
}
```

> [!TIP] Компиляция
> Чтобы запустить этот код, в терминале напишите: 
> `gcc main.c -o myprogram` (компиляция)
> `./myprogram` (запуск)

### 2.2. Указатели (Pointers) — Ваш главный враг и друг
Указатель — это переменная, которая хранит **адрес** в памяти, а не само значение.

```c
int score = 100;
int *p = &score; // p теперь хранит АДРЕС переменной score (например, 0x7ffd5...)

printf("Значение: %d\n", score);     // Выведет 100
printf("Адрес: %p\n", (void*)p);     // Выведет адрес в памяти
printf("По адресу: %d\n", *p);       // Разыменование: выведет 100
```
📺 **Туториал:** [Указатели в C за 15 минут (ОБЯЗАТЕЛЬНО К ПРОСМОТРУ)](https://www.youtube.com/watch?v=zuegQmMdy8M)

### 2.3. Динамическая память (`malloc` и `free`)
Если вам нужен массив, размер которого неизвестен заранее, вы просите память у операционной системы вручную.

```c
#include <stdlib.h> // Для malloc и free

// Просим память под 5 целых чисел
int *arr = (int*) malloc(5 * sizeof(int));

if (arr == NULL) {
    // Память не выдана! Ошибка.
    return 1;
}

arr[0] = 42; // Используем память

// КРИТИЧЕСКИ ВАЖНО: Всегда возвращайте память! Иначе - Memory Leak (утечка)
free(arr);
```

## 👽 Фаза 3: Функциональное программирование на Haskell (Неделя 4)
*Предмет: Funkcionális programozás. Здесь мы ломаем старые привычки.*

Haskell — это чистая математика. **Здесь нет переменных (которые меняются), циклов `for` и классов.** 

### 3.1. Установка и запуск (GHCi)
Для Haskell используется `ghcup`. В терминале вы будете запускать интерактивную консоль: `ghci`.

### 3.2. Базовые принципы
Все функции — чистые. Типы — строгие.

```haskell
-- Определяем тип: принимает два Int, возвращает Int
addNumbers :: Int -> Int -> Int
addNumbers x y = x + y

-- Списки
myList = [1, 2, 3, 4, 5]
```

### 3.3. Сопоставление с образцом (Pattern Matching)
Вместо кучи `if / else` в Haskell используется паттерн-матчинг.

```haskell
-- Описание функции "является ли число нулем?"
isZero :: Int -> String
isZero 0 = "Да, это ноль!"
isZero _ = "Нет, это не ноль." -- подчеркивание означает "любое другое значение"
```

### 3.4. Рекурсия (Замена циклам)
Как посчитать длину списка без цикла `for`?
```haskell
-- Длина пустого списка равна 0
listLength :: [a] -> Int
listLength [] = 0

-- Длина непустого списка = 1 + длина его хвоста (xs)
listLength (x:xs) = 1 + listLength xs
```

## 📐 Фаза 4: Математический фундамент (Опционально, но важно)
*Предмет: Matematikai alapok & Számítógépes rendszerek*

Высшая математика в Венгрии очень формальна. Вам нужно привыкнуть к математической логике и строгим доказательствам.

1. **Теория множеств (Set Theory):** Объединение (∪), Пересечение (∩), Разность (\).
2. **Логика (Boolean Logic):** Конъюнкция (AND, ∧), Дизъюнкция (OR, ∨), Импликация (=>).
3. **Системы счисления:** Перевод из двоичной (Binary) в десятичную (Decimal) и шестнадцатеричную (Hex) системы. 

> [!TIP] Практика
> Попробуйте перевести число `156` в двоичную систему на бумажке. Это базовый вопрос на экзамене по `Számítógépes rendszerek`.
> Изучите оригинальный учебник: [Конспект по математике](1/matalap/jegyzet.pdf).

## 🎓 Фаза 5: Подготовка к экзаменам (Форматы тестов)
Так как вы будете учиться на англоязычной программе (Computer Science BSc), официальные термины будут на английском, но венгерские названия (ZH, Vizsga) всё равно постоянно используются преподавателями и студентами в обиходе. К этому нужно быть готовым:

1. **Mid-term tests / RöpZH (Летучие тесты):** Часто проводятся на первых 10 минутах практики. Пишутся на бумажках или в системе Canvas. Пример: [Вопросы RöpZH по Haskell](1/funprog/Minta%20röpZH%20kérdések_RU.md)
2. **Machine tests / Géptermi ZH (Машинные тесты):** Вас сажают за компьютер без интернета, и вы должны написать программу за 90 минут. Например, алгоритмы на C или Java. Загляните в папку `1/impprog/Tests` чтобы понять уровень жесткости задач.
3. **Final Exams / Vizsga (Теоретические экзамены):** Проходят во время сессии и требуют строгого знания определений наизусть. Например, для гуманитарных предметов: [Шпаргалка с ответами на экзамен](1/jog/Exams%20válaszok.pdf). Обязательно используйте готовые конспекты старшекурсников.
